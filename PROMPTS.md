## Prodesk IT – Sprint 11

This document records the key AI-assisted development prompts and guidance used during the development of the Sprint 11 project.

### 1. Project Structure and Planning

**Prompt:**

"Help organize a full-stack project with separate frontend and backend folders. Suggest a clean and maintainable folder structure suitable for a professional MERN stack application."

### 2. Frontend Development

**Prompt:**

"Help develop the frontend using React.js and Vite. Maintain a clean component structure, reusable code, responsive styling, and proper API integration with the backend."

### 3. Backend Development

**Prompt:**

"Help develop the backend using Node.js and Express.js. Organize the application into models, routes, and server configuration. Follow clean coding practices and maintain proper error handling."

### 4. Frontend and Backend Integration

**Prompt:**

"Guide the integration of the React frontend with the Express backend. Help configure API communication, handle responses, and manage errors during frontend-backend interaction."

### 5. Quality Assurance and Testing

**Prompt:**

"Help identify important test cases for frontend components and backend API routes. Include successful requests, invalid inputs, error responses, and integration testing."

### 6. Debugging and Code Review

**Prompt:**

"Review the project code for common errors, integration issues, inconsistent configurations, and maintainability problems. Suggest practical corrections without unnecessarily changing the existing project structure."
